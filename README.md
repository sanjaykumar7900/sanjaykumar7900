# 🤖 LISA

### Autonomous QA Testing System

<div align="center">

<img src="https://img.shields.io/badge/STATUS-UNDER%20DEVELOPMENT-2563EB?style=for-the-badge"/>
<img src="https://img.shields.io/badge/FOCUS-AI%20%2B%20QA-7C3AED?style=for-the-badge"/>
<img src="https://img.shields.io/badge/TYPE-EXPERIMENTAL-0F172A?style=for-the-badge"/>

</div>

**LISA** is my experimental AI-powered QA system designed to explore how autonomous agents can assist with software testing.

The long-term idea is simple:

> **Give LISA a project → let it investigate → test it → find problems → generate a useful QA report.**

### Current direction

| 🔎 Analyze | 🧪 Test | 🐛 Detect | 📋 Report |
|:---:|:---:|:---:|:---:|
| Project structure | Test scenarios | Potential defects | QA results |
| Dependencies | Automated checks | Failed workflows | Test evidence |
| Application flow | Functional tests | Unexpected behavior | Structured reports |

**LISA is currently under active development and experimentation.**
